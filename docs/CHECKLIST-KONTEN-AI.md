# Checklist Konten Portofolio AI

Gunakan checklist ini untuk mengubah tugas kuliah menjadi studi kasus yang dapat dipahami dosen, recruiter, dan calon kolaborator.

## Profil

- [ ] Nama lengkap dan foto profesional.
- [ ] Headline menyebut AI dan software development.
- [ ] Program studi dan peminatan Komputasi Cerdas.
- [ ] Bio menjelaskan fokus, cara bekerja, dan tujuan.
- [ ] Email profesional.
- [ ] CV terbaru.
- [ ] GitHub dan LinkedIn aktif.

## Setiap proyek AI

- [ ] Judul spesifik, bukan hanya `Tugas Machine Learning`.
- [ ] Masalah dan pengguna yang terbantu.
- [ ] Kontribusi pribadi jika proyek tim.
- [ ] Sumber dataset dan izin penggunaannya.
- [ ] Jumlah data, kelas, distribusi, dan potensi bias.
- [ ] Pembagian train, validation, dan test.
- [ ] Tahap preprocessing.
- [ ] Baseline atau metode pembanding.
- [ ] Model final dan alasan pemilihan.
- [ ] Parameter atau konfigurasi penting.
- [ ] Metrik yang sesuai dengan masalah.
- [ ] Hasil pada test set, bukan training set saja.
- [ ] Confusion matrix atau error analysis bila relevan.
- [ ] Keterbatasan dan rencana pengembangan.
- [ ] Screenshot input, proses, dan output.
- [ ] Demo yang stabil atau video singkat jika demo tidak dapat di-host.
- [ ] Repository dengan README dan cara menjalankan.
- [ ] Tidak ada API key, token, data pribadi, atau file model yang dilarang dibagikan.

## Setiap proyek website

- [ ] Jelaskan kebutuhan pengguna.
- [ ] Jelaskan arsitektur frontend, backend, database, dan API.
- [ ] Tampilkan desktop dan mobile.
- [ ] Uji keyboard, label form, kontras, dan alt text.
- [ ] Uji loading, empty, success, dan error state.
- [ ] Uji performa gambar dan ukuran bundle.
- [ ] Tautan production dan repository dapat dibuka.

## Urutan proyek pada beranda

1. Proyek AI terbaik dengan hasil terukur.
2. Proyek yang menunjukkan integrasi AI dan web.
3. Proyek dengan kontribusi tim atau pengguna nyata.
4. Proyek eksplorasi tambahan.

Tiga sampai enam proyek kuat lebih baik daripada banyak proyek tanpa penjelasan.

## Contoh struktur ringkasan

```text
Saya membangun aplikasi klasifikasi penyakit daun untuk membantu pengguna mengenali gejala awal dari foto. Model dilatih pada [jumlah] gambar dan mencapai [metrik] pada test set. Saya mengerjakan preprocessing, eksperimen model, API prediksi, dan antarmuka responsif.
```

## Bukti yang dapat ditampilkan

- Angka evaluasi yang disertai konteks.
- Tabel perbandingan model.
- Grafik training dan validation.
- Confusion matrix.
- Cuplikan arsitektur.
- Umpan balik pengguna.
- Dokumentasi keputusan teknis.
- Link commit, issue, atau pull request yang relevan.

Jangan mengarang metrik. Jika proyek masih berjalan, tulis `experiment in progress` dan jelaskan apa yang sedang diuji.
